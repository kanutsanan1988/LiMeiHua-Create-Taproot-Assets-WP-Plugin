== Features ==

* **Create Tokens** - Easily create Taproot Assets tokens with just a few clicks
* **Token Types** - Support for Fixed Supply, Mintable, and Burnable tokens
* **Gas Estimation** - Real-time calculation of transaction fees
* **Transaction History** - Track all token creation and management activities
* **Admin Dashboard** - Comprehensive dashboard for managing all your tokens
* **Widget Support** - Display your tokens in sidebar widgets
* **Shortcode Support** - Embed token forms and lists anywhere on your site
* **Multi-language** - Supports multiple languages for global accessibility
* **Bitcoin Lightning** - Direct integration with Bitcoin Lightning Network
* **Taproot Assets Protocol** - Uses the official Taproot Assets Protocol API

== Installation ==

1. Upload the plugin files to the `/wp-content/plugins/limeihua-taproot-assets` directory
2. Activate the plugin through the 'Plugins' menu in WordPress
3. Go to Taproot Assets menu to configure settings
4. Create your first token!

== Usage ==

**Creating a Token:**
1. Go to Taproot Assets → Create Token
2. Fill in the token details (name, symbol, supply, etc.)
3. Choose the token type (Fixed, Mintable, or Burnable)
4. Enter your Bitcoin Lightning wallet address
5. Click "Create Token"

**Managing Tokens:**
1. Go to Taproot Assets → My Tokens to see all your tokens
2. For Mintable tokens, click "Mint" to create additional tokens
3. For Burnable tokens, click "Burn" to destroy tokens
4. View transaction history and token details

**Using Shortcodes:**
* `[limeihua_create_token]` - Display the token creation form
* `[limeihua_tokens_list]` - Display a list of all your tokens

**Using Widgets:**
1. Go to Appearance → Widgets
2. Add the "LiMeiHua Taproot Assets" widget to your sidebar
3. Configure the widget title and settings

== Configuration ==

**API Settings:**
1. Go to Taproot Assets → Settings
2. Enter your Taproot Assets API URL (or leave blank for simulator mode)
3. Configure other options as needed
4. Save settings

== Frequently Asked Questions ==

**Q: Do I need a Bitcoin wallet?**
A: Yes, you need a Bitcoin Lightning Network wallet address to create tokens.

**Q: What is the difference between token types?**
A: Fixed Supply tokens cannot be changed after creation. Mintable tokens can have more created. Burnable tokens can be destroyed.

**Q: How much does it cost to create a token?**
A: You only pay Bitcoin network fees. The plugin itself is free.

**Q: Can I use this on a live site?**
A: Yes, but make sure to properly configure your API settings and test thoroughly first.

**Q: Is my data safe?**
A: All token data is stored securely in your WordPress database. Your private keys are never stored by the plugin.
